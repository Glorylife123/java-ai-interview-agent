# Java 基础语法笔记

## 1. Java 程序入口

1. Java 程序通常从 `main` 方法开始执行。
2. 标准入口写法是 `public static void main(String[] args)`。
3. `public` 表示这个方法可以被 JVM 从外部调用。
4. `static` 表示不需要创建对象就能调用。
5. `void` 表示这个方法没有返回值。
6. `String[] args` 用来接收命令行参数。

## 2. 基本类型

7. Java 有 8 种基本类型。
8. 整数类型有 `byte`、`short`、`int`、`long`。
9. 浮点类型有 `float`、`double`。
10. 字符类型是 `char`。
11. 布尔类型是 `boolean`。
12. `int` 是常用整数类型，默认适合大多数整数计算。
13. `long` 用于更大的整数，字面量通常加 `L`。
14. `double` 是常用小数类型。
15. `boolean` 只有 `true` 和 `false` 两个值。

## 3. 变量与运算符

16. 变量需要先声明类型，再保存数据。
17. 变量名要表达含义，例如 `score`、`age`、`total`。
18. 算术运算符包括 `+`、`-`、`*`、`/`、`%`。
19. 比较运算符包括 `>`、`>=`、`<`、`<=`、`==`、`!=`。
20. 逻辑运算符包括 `&&`、`||`、`!`。
21. `=` 是赋值，`==` 是比较两个值是否相等。

## 4. 流程控制

22. `if` 用于条件判断。
23. `else if` 用于多个条件分支。
24. `else` 用于兜底分支。
25. `for` 适合次数明确的循环。
26. `while` 适合条件满足就继续执行的循环。
27. 循环中可以用 `break` 结束循环。
28. 循环中可以用 `continue` 跳过本次循环。

## 5. 方法

29. 方法用于把一段可复用逻辑封装起来。
30. 方法可以有参数，也可以没有参数。
31. 方法可以有返回值，也可以用 `void` 表示无返回值。
32. 方法名通常使用小驼峰命名，例如 `calculateAverage`。
33. 写方法时要尽量让一个方法只做一件清楚的事。

## 6. Day 1 八股问题

34. Java 基本类型：`byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean`。
35. `int` 是基本类型，`Integer` 是包装类，可以用于泛型和集合。
36. `==` 比较基本类型的值；比较对象时，比较的是引用地址。
37. `equals` 默认也是比较对象地址，但很多类会重写它，例如 `String` 比较内容。
38. Java 是值传递；传对象时传递的是对象引用的副本。
39. `String` 不可变是因为内部值不能被修改，这有利于安全、缓存和哈希稳定。
