# java-ai-interview-agent

智能面试刷题与 AI 面试 Agent 平台。

这个项目用于记录 Java 后端学习过程，并逐步实现一个面向面试准备的练习系统。短期目标是完成 Java 基础、算法题、数据库和 Spring Boot 的训练；长期目标是构建一个可以管理题库、生成追问、模拟面试和复盘答案的 AI 面试 Agent 平台。

## Day 1

- 恢复 Java 基础语法。
- 记录基本类型、流程控制和方法笔记。
- 完成 `JavaBasicDemo`。
- 完成 LeetCode 1 两数之和的暴力法和 HashMap 法。
